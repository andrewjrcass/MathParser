# MathParser 2.0.5.7

This is the first planned public Windows x64 binary release of MathParser.

## Highlights

- scientific calculations with physical units and dimensional validation;
- vectors, matrices and complex numbers;
- canonical mathematical presentation;
- optimized indexed summations and products;
- plotting and scientific graphics;
- structural/FEM, geotechnical, hydraulic, thermal and electrical capabilities;
- offline Portuguese/English Help;
- workspace and source-linked scientific preview.

## Download

Download the portable ZIP, extract the complete folder, and run `mathparser_gui.exe`.

## Public Portable profile

The first public portable profile intentionally excludes the external Python bridge source file. Python integration is therefore not included in this package.

## Integrity

Verify the downloaded package against `SHA256SUMS.txt`.
