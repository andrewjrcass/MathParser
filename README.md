# MathParser

**MathParser** is a scientific and engineering calculation environment with physical-unit awareness, dimensional validation, mathematical presentation, plotting, numerical methods, and engineering-domain extensions.

## Current public release target

**MathParser 2.0.5.7 — Windows x64**

The first public distribution is planned as a **portable binary package**. This repository is a distribution/documentation repository and does **not** contain the MathParser source code.

## Main capabilities

- unit-aware scalar calculations;
- vectors and matrices;
- complex numbers;
- derivatives, integrals, summations and products;
- numerical methods and sparse linear algebra;
- scientific plotting and SVG composition;
- structural engineering and FEM tools;
- geotechnics;
- hydraulics;
- thermal engineering;
- electricity;
- experimental statistics;
- offline Help in Portuguese and English;
- project/workspace support;
- scientific HTML/KaTeX presentation.

## Download

Use the **Releases** section of this repository to download the current Windows x64 portable package.

> The executable packages are distributed as release assets. Source code is not published in this repository.

## Quick start

1. Download the latest `MathParser-<version>-Windows-x64-Portable.zip` from Releases.
2. Extract the entire ZIP to a writable folder.
3. Run `mathparser_gui.exe`.
4. Keep the package folder intact; Help, themes, extensions and offline assets are loaded from that folder.

See [Getting Started](docs/getting-started.md).

## Offline operation

The core scientific runtime and mathematical rendering assets are packaged for offline use. Features that explicitly integrate with external components may have additional requirements.
