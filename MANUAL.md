# MathParser Manual — 2.0.7.139

This public package contains the complete MathParser offline Help/manual in Portuguese and English.

## Portuguese

Open `help/pt/index.html`.

## English

Open `help/en/index.html`.

The offline manual covers getting started, syntax, units and conversions, variables and expressions, vectors, matrices, tables, complex numbers, scripting and flow control, functions and scope, files and modules, document directives and settings, plots, SVG composition, numerical methods, statistics and the scientific/engineering function libraries.

The manual is fully local and can be used without an Internet connection.
