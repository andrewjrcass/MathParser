# MathParser Public Roadmap

## Current public baseline

**MathParser 2.0.7.139 — Windows x64**

The current public baseline consolidates the high-performance scientific/document renderer, canonical formatting for specialized scientific operations, the Field visualization foundation, synchronized Portuguese/English offline Help, and release/runtime version consistency checks.

## Next development line

The next engineering step resumes the Field System integration work: connecting the consolidated Field visualization facade to Inspector/GUI/Graphics consumers while preserving the separation between Numerical and Rendering.

New public releases are published only after the maintained regression and distribution gates pass.
