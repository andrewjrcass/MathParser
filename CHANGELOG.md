# Changelog

## 2.0.5.7

First planned public binary distribution baseline.

Highlights of the current 2.x baseline include:

- consolidated and audited 1.x scientific feature line;
- Field System groundwork for multi-domain numerical assembly;
- optimized indexed summations/products, including closed-form polynomial summation;
- canonical mathematical presentation for indexed sums/products;
- monotonic `timer` support for script benchmarking;
- improved WebView ↔ source-editor mapping;
- optimized HTML rendering path;
- offline Help in Portuguese and English.

This public changelog intentionally describes user-visible behavior and does not include private source history.
